Server

ikmal only ever talks to a server you run. The default is the ikmal quality proxy, which adds the local quality checks on top of LanguageTool. Point it at port 8097 to use LanguageTool alone.

Privacy

This extension may only reach 127.0.0.1 and localhost; that restriction is declared in its manifest, so the browser enforces it rather than asking you to trust a promise. There is no analytics call, no update ping, no account, and no remote server to fall back to. Your text never leaves your machine.
