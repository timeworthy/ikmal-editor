Ikmal Editor
Why it exists

LanguageTool is powerful. Running it locally is a chore.

A local server means managing Java runtimes, long command-line flags, CORS headers, FastText model paths, and a background daemon you have to keep alive yourself. ikmal editor does that part.

Optional · opt-in

A local quality model, if you want one.

The quality sidecar runs on port 8098 and adds deterministic paragraph-window repetition, word-family echo, and conservative pronoun–antecedent analysis. It does not send text anywhere. A separate Transformers.js / ONNX adapter can add local transformer suggestions through the same sidecar.

Start the sidecar

port 8098
$ ikmal-editor --quality-server

Deterministic checks only. Nothing is downloaded.

Add the transformer

opt-in · ~650 MB
$ ikmal-editor --quality-setup

Installs the adapter under ~/.ikmal-editor/quality/ and caches the quantized model. Downloaded only when you run this — never during normal startup.

One endpoint for extensions

port 8096
$ ikmal-editor --quality-proxy
  http://127.0.0.1:8096/v2

The proxy forwards native LanguageTool matches from 8097, adds quality matches from 8098, removes duplicate edits, and resolves overlaps in favour of the native result.

Install

Six ways in. All of them one line.

Updates stay with whatever manager you already use: brew upgrade languagetool, docker pull, or apt upgrade update the engine independently, and ikmal editor picks up the new binary without touching your daemon.

Homebrew

macOS · Linux
$ brew tap timeworthymedia/tap
$ brew install timeworthymedia/tap/ikmal-editor
$ ikmal-editor -configure-apps

Scoop

Windows 10 · 11
$ scoop bucket add ikmal …
$ scoop install ikmal-editor

Native 64-bit executable. No WSL, no Docker Desktop, no virtual machine.

Docker

any host
$ docker pull ghcr.io/timeworthymedia/ikmal-editor

Containerised LanguageTool images update independently through standard image pulls.

Raspberry Pi

arm64 · armv7
$ ./ikmal-editor-linux-arm64

Pre-compiled binaries for Pi 3, 4, and 5 — 1-click execution, no cross-compilation.

Connected apps

One command points your tools at the local server.

ikmal-editor -configure-apps routes the extensions and plug-ins you already have to http://127.0.0.1:8097/v2/check. Installing those extensions stays your call — ikmal editor never downloads them for you.

Chrome Firefox Safari Edge Apple Mail Microsoft Word LibreOffice VS Code Obsidian Trilium Notes

Anything that speaks the LanguageTool API works unchanged — including the community Obsidian plug-in and the Trilium Notes plug-in. Point it at your port and nothing else about your setup has to move.

Privacy

Your text is never sent anywhere.

The LanguageTool server ikmal editor manages listens on 127.0.0.1:8097 and nothing leaves the loopback interface. The one outbound request the binary makes on its own is a daily update check for a static JSON file.

No identifier

No UUID, no hostname, no username, no OS or hardware details. There is no request body and no query string.

One timestamp

It stores only a timestamp in ~/.ikmal-editor/.update-check to rate-limit itself to once every 24 hours.

Fails silently

Three-second timeout, runs after the server is already up, and never blocks startup.

$ikmal-editor -no-update-check # per run
$export IKMAL_EDITOR_NO_UPDATE_CHECK=1 # permanently

Aggregate download counts come from the GitHub Releases API, not from the binary.

FAQ

Questions people actually ask.

Does ikmal editor send my text to third-party cloud servers?
No. It runs a 100% local LanguageTool server on http://127.0.0.1:8097. All text analysis happens locally on your computer.
Will anything break if I already use LanguageTool?
No. ikmal editor is a supervisor, not a fork: it launches the official LanguageTool distribution and answers on the standard API, so existing extensions, plug-ins, and settings keep working. Rule packs arrive as ordinary matches, and you can turn them off.
Does Windows require WSL?
No. ikmal-editor-windows-amd64.exe is a native 64-bit Windows application that runs directly on Windows 10 and 11 without WSL, Docker Desktop, or Linux virtual machines. Java is auto-detected via javaw.exe, so the server runs silently with no command prompt windows.
Will Windows Defender Firewall pop up an alert?
No. The local server binds specifically to loopback (http://127.0.0.1:8097/v2/check), which prevents Windows Defender Firewall prompts.
Does it download browser extensions for me?
No. ikmal editor configures settings for the applications and extensions you have installed, but downloading browser extensions or office plug-ins is your responsibility. Once they are installed, ikmal-editor -configure-apps routes them to your local server.
How do I add my own rules?
Add custom LanguageTool XML rules to ~/.ikmal-editor/rules/style_conciseness.xml, or edit rules/style_conciseness.xml in the repository directly.
How do I uninstall it completely?
Run ikmal-editor -uninstall. On macOS and Linux this unloads LaunchAgent and systemd daemons, deletes browser policy files, stops container instances, and purges ~/.ikmal-editor. On Windows, -uninstall removes the startup registry key, clears Chrome and Edge managed policies, terminates background Java processes, and purges %USERPROFILE%\.ikmal-editor.
